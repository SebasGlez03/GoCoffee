# GoCoffee

Backend de suscripciones para café con NestJS + Prisma + PostgreSQL (Supabase).

## Requisitos
- Node.js 20+
- npm
- PostgreSQL / Supabase
- VS Code (opcional, para usar peticiones.http)

## 1. Clonar y instalar
```bash
git clone <repo-url>
cd go-coffee
npm install

## 2. Correr el proyecto
npm run start:dev
